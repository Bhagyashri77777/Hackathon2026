# 🛡️ TrustShield: Multi-Modal Fraud Detection System

An AI-powered "Zero-Effort" safety engine designed to detect phishing URLs and Deepfake audio in real-time. The core mission of this project is to provide accessible digital safety for senior citizens and first-time internet users.

### 🚀 Key Features
* **Phishing URL Detection:** Real-time analysis to identify malicious links.
* **Audio Analysis:** Deepfake detection to verify the authenticity of voice notes.
* **Zero-Effort UX:** Designed with extreme simplicity for vulnerable user groups.

### 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript
* **Backend:** Python (Flask/FastAPI)
* **ML Models:** Scikit-Learn, Pre-trained Audio Analysis APIs
